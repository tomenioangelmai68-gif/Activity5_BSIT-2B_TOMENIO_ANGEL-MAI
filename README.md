# Fundamental Data Structures: Stacks and Queues

## Description
This project demonstrates four data structure implementations: Array Stack, Linked Stack, Array Queue, and Linked Queue. It also includes a balanced parentheses checker and a print queue simulation.

## Files
- array_stack.py - Stack implementation using an array.
- linked_stack.py - Stack implementation using a linked list.
- array_queue.py - Circular queue implementation using an array.
- linked_queue.py - Queue implementation using a linked list.
- main.py - Menu-driven program and test driver.
- analysis.md - Explanation of linked stacks and circular queues.

## How to Run
1. Make sure Python is installed.
2. Place all Python files in the same folder.
3. Open main.py using Python IDLE.
4. Press F5 to run the program.
5. Choose an option from the menu.

## Features
- Stack push, pop, and peek operations.
- Queue enqueue, dequeue, and peek-front operations.
- Empty and full checks where applicable.
- Underflow and overflow handling.
- Balanced parentheses checker.
- Print queue simulation using job IDs and page counts.

## Testing
Test normal operations, underflow, overflow, circular queue behavior, balanced parentheses, and FIFO print job processing.
